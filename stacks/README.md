# Software stacks

Knowledge that depends on the user's software setup rather than the hardware: emulation suites, frontends, launchers.
One folder per stack (`stacks/emudeck/`, `stacks/retrodeck/`...), with a `README.md` covering paths, launchers,
controller setup and per-emulator quirks. The hardware-profile skill detects installed stacks and lists the folders
in `notes/hardware.md`. Contributions welcome (contribute skill).
